# Historical Home Assistant 2026.11 beta smoke checklist

Home Assistant 2026.11.0 was released as stable on **2026-11-04**.
This earlier beta-specific checklist is superseded by the
[HA 2026.11 stable compatibility and Marketplace smoke checklist](./ha-2026.11-smoke.md).

Use the new checklist for all current compatibility or release-readiness
decisions. The previous beta checklist was a test plan, **not evidence of a
passing integration test**, and should not be used to claim that the current
DKN Cloud release works on HA 2026.11. The minimum has since advanced to HA **2026.11.0**.
